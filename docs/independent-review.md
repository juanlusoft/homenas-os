Regresión original mantiene assertion DB abierta, y se añadió fetch DDNS pendiente al cerrar: ambos PASS; suite global backend 33/33 PASS.

**IR-16, alta, bloqueo de cuenta concurrente confirmado:** login sólo leía failCount antes de await bcrypt.compare.
